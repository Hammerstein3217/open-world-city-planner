# 输入、询问与来源

| 未知 | 影响 | 一轮问法 |
|---|---|---|
| 移动与镜头 | 摆荡锚点、车转弯、步行可读性需要不同尺度 | 主要步行、驾车还是高机动移动？镜头与已有实测参数是什么？ |
| 面积与轮廓 | 路长、内容、交通需求 | 图有比例尺吗？哪些边界、地标必须保留？ |
| 世界观、目标与平台 | 时代设施、形成原因、让步顺序 | 哪些设定不能改？本阶段最优先验证什么、面向什么平台？ |

最多 3 个问题不等于问满，先在材料里找答案。必要信息未答时可整理研究与关系图，不能编造确定的尺寸和通过时间。矛盾不能用两个互斥的隐含假设覆盖。

## 工作状态

- `blocked_for_final_geometry`：主移动／尺度未知，等待回答前只做带标签分支。
- `provisional`：次要信息用假设，写替换影响与确认人。
- `fiction_demo`：用户要求测试范例，自主设计并集中标注虚构前提。本包属于此状态，示例背景不是用户原始世界观。

## 声明分类

每项有 `id, kind, text, sourceIds, locator, premises, reasoning, confidence`。

| kind | 依据 | 不能声称 |
|---|---|---|
| user_given | 实际用户原文与定位 | 用户没有给的城市历史 |
| attachment_summary | 附件段落，保留概括／归纳类别 | 已看原视频、讲者逐字原话 |
| original_verified | 实际检查的一手页面及检查范围 | 场次页足以证明方法细节 |
| inference | 前提声明 ID＋解释＋可推翻条件 | 当成现实事实或已确认设定 |
| fictional | 为本项目新增的设定 | 当作考证或 GDC 结论 |
| measurement | 环境、版本、方法、记录与样本 | 用目标、估算或虚构样本代替实测 |

置信度不是测试成功率。来源台账含作者／主体、地址、定位、日期、检查范围、局限、可迁移设计与不可照搬项。图片需许可信息；无许可可链接官方作品，或用标为原创的结构示意，不能冒充实景。

## 因果最小单元

`trigger → actor/resource/constraint → decision → spatialDelta → residue → playerEffect → validation`。
事件用 `dependsOn` 关联上游，`claimIds` 关联证据，指定城区／POI／道路。`counterfactual` 记录其他合理选择。改上游后列出失效的下游，不只改故事文字。

示例：航道淤积（原创）→ 联合社有资本但旧港不能扩船坞（原创）→ 外湾建新港（推断）→ 旧仓转租（空间后果）→ 断轨穿进菜摊（索引）→ 快直货路过渡成弯曲集市（体验）→ 测导航与拥堵（待测）。
