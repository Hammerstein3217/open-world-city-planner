# 工作流、退出与变更

本表按附件第八章操作化，不是 GDC 原始流程图。Define → Research → Experiment → Confirm → Execute → Reflect 可以往返。

| 阶段 | 交付 | 退出证据／未达成时 |
|---|---|---|
| 0 定义 | 输入表、目标层级、冲突、规模口径 | 最高目标可指认；硬未知未答不冻结 |
| 1 研究 | 四栏参考、世界观声明、坐标和保留区 | 参考有用途、定位与边界 |
| 2 骨架 | 轮廓、地标、自然空间、关键路、高度 | 形态和路径分别解释，入口边界可读 |
| 3 因果／区域 | 事件链、迁移、空间传记、设施与阵营 | 新旧并存有理由，时间和引用成立 |
| 4 实验 | 单变量对照、有限视野、连续移动与恢复 | 原始数据和结论；无数据仍是目标 |
| 5 确认 | 跨区切片、任务交通流式、余量和回退 | P0 关闭或有证据地由负责人接受 |
| 6 执行 | rough、锁定指标、道具缓冲、内容预留 | 增内容后复测，未知不留给美术补洞 |
| 7 复盘 | 反馈—目标—决定、失效前提、下一轮检查 | 经验形成可执行模板更新 |

先找水源、食物、交换、庇护、交通或权力为何聚集。增长有资金、劳动力和通道；衰退解释为何无人修复；更新解释产权、资金和受益者。允许功能混合，不把生活拆成孤立的纯色区域。

建筑关系需解释就业与住房、沿客流商铺、面向服务人口的学校诊所、工业危害隔离为何成功或失效。用院落、首层开口、屋顶加建和维护痕迹表达经济。常住人口≠屏幕同现 NPC，设定面积≠可玩面积，压缩比例独立记录。

阵营写谁有权、凭什么、如何执行。显性地权与暗面控制分开；收费、许可、水电、巡逻、工会、债务或互助落到空间与双线索。

道路区分时代与模式；自然欲望路径不能自动成为干道。港口、关口、船渡、停车、楼梯、坡道落到入口节点。技术不支持复杂路口时，封闭一支并验证绕路，而不是仅文字宣称兼容。

变更流程：修改事件／比例尺／机制／权限 → 找依赖声明与事件 → 枚举对象 → 改几何、数据、展示 → 重跑相关路线 → 旧实测标需复测。测量绑定版本，不沿用到变更后的几何。

交付区分两档：**规划可评审**＝逻辑、来源、数据和 H5 已检，缺失引擎证据显著列出；**可进昂贵生产**＝额外有角色、镜头、困难地形、跨区、交通、内容、流式、平台的有效证据和团队确认。
